升學管道簡介字典

分區大免 (免試入學)

全國九成以上國中生參與的最終主流管道。主要依據「會考成績」、「志願序」及「多元學習表現積分」進行分發與超額比序。大免放榜後整個升學季即宣告結束。

完免 / 優免 / 直升

  • 完全免試：為減輕升學壓力，針對特定學習區內學生開放，完全不採計會考成績。
  • 優先免試：鼓勵就近入學。基北區分新北公立優免與北市優免兩類，北市優免分兩階段報名，請留意時程。
  • 直升入學：提供給設有國中部的「完全中學」校內國三生直升本校高中的專屬名額。

五專 (優免 / 聯免)

適合志向明確（如護理、外語、電機等），且希望提早接觸專業科目的學生。

  • 五專優免：全國一區，透過電腦系統統一選填志願分發。
  • 五專聯免：分北中南三區，最大特色是「現場撕榜」。學生依總積分順序到場，看見榜單上有空缺的科系直接撕下即錄取。

特招 / 技優 / 實用技能

  • 特色招生(群科)：高職專屬，不看會考成績，需透過「術科實作」測驗錄取（如餐飲切菜、設計畫圖）。
  • 特色招生(學科)：少數明星高中專屬，會考達標後需額外加考學科測驗。
  • 技優甄審：針對在國中技藝教育學程或各類技藝競賽中表現優良的學生。
  • 實用技能學程：以就業導向為主，著重實作技能，多免收學費。

藝才 / 體育 / 運動績優

針對具備特殊才藝專長的學生。包含音樂、美術、舞蹈、戲劇班及各校體育班。
此類管道通常需提早在 4、5 月參加專屬的術科測驗或檢定，並以此成績作為後續分發的依據。
